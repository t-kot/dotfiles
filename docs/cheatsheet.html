tmux のコピーモード

コピーモードに入ると、入力ソースが自動で英数に切り替わります。日本語入力のままでも y などがすぐ効き、抜けると元の入力ソースに戻ります。

prefix [ / ホイールで上へコピーモードに入る
v選択を開始
Ctrl+v矩形選択に切り替え
yクリップボードにコピーして抜ける
Esc選択中なら選択を解除、何も選択していなければ抜ける
ドラッグマウスで選択（コピーはされない。y でコピー）
選択中にクリックコピーモードを抜ける
/ ? → n N下方向 / 上方向に検索し、次 / 前の一致へ移動

Ghostty ghostty/config

Cmd+u背景の透過と非透過を切り替える
Cmd+クリックURL を開く（tmux の外）
Cmd+Shift+クリックURL を開く（tmux の中）。Claude Code などが出すリンク（OSC 8）も開ける
Cmd+Shift+,設定を再読み込み
左 OptionAlt キーとして働く（右 Option は従来どおり特殊文字の入力）
補足　透過度（background-opacity）の変更は、Cmd+q で Ghostty を完全に終了して起動し直すまで反映されません。

Git git/config / ~/.gitconfig

git diff / git log -pdelta で色分け・行番号付きで表示。n / N で次 / 前のファイルへ
git push新しいブランチでも、そのまま push すればリモートに作られる（-u が不要）
git commit1Password で自動署名（Touch ID の承認が出る）。GitHub では「Verified」と表示される
git commit --no-verifydotfiles の gitleaks チェックを飛ばす（誤検知のときだけ使う）
lglazygit でステージ・コミット・ブランチを操作

自動で効いている設定

コンフリクトの表示元の内容も並べて表示する（zdiff3）
同じコンフリクト一度解決したものは次から自動で解決する（rerere）
git branch最近コミットした順に並ぶ
git fetchリモートで消えたブランチも掃除する

Claude Code

ステータスライン

dotfiles main [wt:fix-x] · Opus · ctx 63% · 5h 23%
左からディレクトリ・ブランチ・worktree 名・モデル・コンテキストの使用率・5時間枠の使用率
ctx の色緑 → 50% から黄 → 80% から赤。赤になったら /compact するか、新しいセッションに切り替える目安

並列作業

cw 名前tmux の新しいウィンドウで claude --worktree 名前 を起動する（1ウィンドウ = 1 worktree = 1エージェント）worktree は .claude/worktrees/名前、ブランチは worktree-名前。同じ名前で実行すると再開する
claude -cこのディレクトリの直前の会話を再開する
claude --resume再開する会話を一覧から選ぶ
